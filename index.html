Rasha Shield

Ads leave.
The page stays.

Rasha Shield is on from the first page. It blocks ad servers, trackers, popups and leftover ad space. Strong mode also catches same-site ad paths and YouTube ads.

  • Rules run in the browser

    Matching happens on this device. Page content is not sent to a filter service.

  • One site at a time

    Shields down removes the rules for that site and reloads it. Other tabs keep their protection.

  • Its own engine and rules

    Written for Vaayvu. No EasyList, EasyPrivacy, uBlock Origin or AdGuard rule sets are used.

Privacy

Local by default.
Yours where it leaves.

Vaayvu does not build an ad profile or send your reading to an analytics service. When you choose to sync, the data goes to the server you entered.

Shield stays local

Rule matching happens in the browser, so the pages you open stay on the device.

No telemetry backend

The anonymous-usage choice is stored on this device in this build. There is no reporting endpoint yet.

Private windows

Private visits stay out of history, session restore and sync, and close with the window.

Your sync server

Bookmarks and regular open tabs go to the Vaayvu Sync origin you configure. There is no Vaayvu cloud.

Questions

The short answers.

Does Vaayvu use EasyList or uBlock filters?

No. Rasha Shield runs Vaayvu's own engine and rule data. EasyList, EasyPrivacy, uBlock Origin and AdGuard rule sets are not part of the build.

Is there telemetry?

There is no telemetry backend in this build. The anonymous-usage choice is stored on the device only; reporting is planned for a future update and will be described when it exists.

Do extensions run JavaScript?

No. Vaayvu accepts stylesheet-only packages that change how listed sites look. A scripted extension runtime is not included.

Can I sync without Vaayvu servers?

Yes. Sync is the self-hosted Vaayvu Sync service in the source tree. Enter its origin when you create an ID; bookmarks and regular open tabs go there, not to a Vaayvu cloud.

What does the iPhone build need?

Build the Xcode project with your own Apple team and provisioning profile. Development-signed builds install on registered devices; no IPA is published on this site.

Is the source open?

Vaayvu's own browser, native hosts and sync service are MIT-licensed. Third-party components keep their own notices, included with each release.
