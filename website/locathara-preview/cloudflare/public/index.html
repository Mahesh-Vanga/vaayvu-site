What's inside Vaayvu

Four features.
Zero extensions.

Everything built in. No extension store, no permissions, no background scripts.

Built-in Ad Blocking

Local-first tracker blocking. No EasyList. Rules compile to bytecode and match on-device. Strong mode catches YouTube ads.

Spaces

Work, study, and personal tabs stay separated. Each space has its own tabs, pins, and accent color. Switch instantly.

India Search (Optional)

On-device mode. Curated directories for pincodes, IFSC, gov services. Works offline. No query logging.
