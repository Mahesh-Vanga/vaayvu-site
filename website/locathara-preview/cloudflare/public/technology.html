Rasha Shield Engine

VFD — Vaayvu Filter Definition

Custom rule format compiled to bytecode. Declarative, typed, and verifiable. Rules express "block this domain on these pages" not "match this regex." Enables strong mode, per-site toggles, and instant reload without re-parsing.

Bytecode VM Zero network Cosmetic cleanup Per-site state

Rule Compilation Pipeline

VFD source → AST → Type-check → Bytecode → Serialized .vfd.bin → Loaded by VM. Compilation happens at build time; runtime only loads verified bytecode. No JIT, no regex at runtime.

AOT compilation Type-safe Verifiable ~2MB rules

Strong Mode

Catches same-site ad paths and YouTube ads by analyzing request chains and response patterns. Uses heuristics + allowlisted first-party domains. Opt-in per site.

Heuristic YouTube support Per-site opt-in

Vaayvu Sync

End-to-End Encryption

Passphrase → Argon2id (t=3, m=64MB, p=4) → 32-byte key → AES-GCM encryption. Each record encrypted independently. Server stores only ciphertext + nonce. Key never leaves device.

Argon2id AES-GCM Per-record nonce No key escrow

Sync Protocol

HTTP/JSON over TLS. Client pushes/pulls encrypted records. Conflict resolution: last-write-wins with vector clocks; manual merge UI for conflicts. Supports incremental sync via timestamps.

HTTP/JSON Vector clocks Incremental Open protocol

Self-Hosted Deployment

Single Go/Rust binary (~8MB). Docker image (~12MB). Runs on any Linux/BSD. SQLite or PostgreSQL backend. Reverse proxy with TLS (Caddy/Traefik/NGINX). Health endpoint for orchestration.

Single binary Docker SQLite/PG Health checks

Platform Integration

macOS / iOS — Swift & WKWebView

Swift package wraps Rust dylib via C FFI. WKWebView for rendering. WKScriptMessageHandler for bidirectional communication. Keychain for credentials. UserNotifications framework. App Sandbox compatible.

WKWebView App Sandbox Keychain Developer ID

Windows — WebView2 & WinRT

C++/WinRT host with WebView2 (Chromium). Rust dylib loaded via LoadLibrary. Win32 message loop. Credential Manager for passwords. Windows Push Notification Services (WNS) optional. Portable ZIP, no installer.

WebView2 WinRT Portable Credential Manager

Android — Kotlin & Android WebView

Kotlin/JNI bridge to Rust dylib. Android WebView (system component, auto-updated). WorkManager for background sync. BiometricPrompt for unlock. AutofillService integration. Quick Settings tile. 5.7 MB APK.

Android WebView WorkManager BiometricPrompt AutofillService

Extensions & Privacy Architecture

Style-Only Extensions

CSS packages scoped to origins. No JavaScript execution, no background pages, no permission prompts. Declarative manifest (origin + CSS). Loaded via user stylesheet injection. Zero attack surface.

CSS only No JS Scoped User stylesheet

Local-First Privacy

No telemetry backend in shipping builds. No crash reporting to our servers. No update checks that fingerprint you. Update check fetches static JSON (no client ID). All processing on-device. No accounts required.

Zero telemetry Static updates No accounts On-device only

Per-Site Shield State

Turn shields down for one site — it reloads instantly. Other tabs keep full protection. State persists per-origin, not globally. No "pause everywhere" that leaks your privacy. Stored in origin-keyed IndexedDB.

Per-origin Instant reload Others protected IndexedDB
