How we operate

Default to native

If the platform provides it, we use it. Web views, keychain, notifications, window management — platform APIs first. No cross-platform abstractions that leak.

Ship the smallest thing that works

No feature flags for unfinished work. No "coming soon" pages. If it's not ready, it doesn't ship. Users get complete features or nothing.

Document the sharp edges

Every limitation, every platform difference, every "why" — written down for users and future contributors. Honest documentation prevents wasted time.

No telemetry without consent

And even then, only local. We don't run a telemetry pipeline and have no plans to. The browser checks for updates by fetching a static JSON file — no client identity sent.

Profit from value, not data

If we ever charge, it'll be for something you'd pay for — not for selling your attention. No ads, no data brokering, no "free tier" that monetizes you.

History

Timeline

From idea to browser — the honest version.

2024 — Foundation

Locathara founded. Vaayvu Browser development begins. Rust core architecture designed.

Early 2025 — Rasha Shield

Custom ad-blocking engine (VFD) written from scratch. Bytecode VM, strong mode, per-site state.

Mid 2025 — Sync & Spaces

Self-hosted sync server with E2E encryption. Spaces for tab isolation. Platform shells mature.

Late 2025 — India Search

Optional on-device search mode for Indian directories. Pincode, IFSC, gov services offline.

2026 — v0.0.23 Release

Public release. macOS, Windows, Android, iOS (self-build). MIT licensed. Open source everything.
